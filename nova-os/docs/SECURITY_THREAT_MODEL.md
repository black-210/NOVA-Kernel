# نموذج التهديد الأمني المتكامل لنظام التشغيل NOVA OS
## Threat Model & Multi-Layer Defense Architecture

### 1. تصنيف التهديدات وحدود المسؤولية البرمجية والعتادية
تلتزم هندسة NOVA OS بالوضوح التام في تصنيف ما تستطيع البرمجيات حمايته وما يتطلب عتاداً موثوقاً:

```
[تهديدات برمجية Software Threats] -------------> حماية مؤكدة برمجياً 100% (W^X, NX, Canaries, Capabilities)
[هجمات العتاد وDMA Attacks] ------------------> مشروطة بدعم عتادي (IOMMU / VT-d / AMD-Vi)
[هجمات الإقلاع والفيزيائية Cold-Boot] --------> مشروطة بجذر ثقة عتادي (TPM 2.0 / Secure Boot)
[هجمات القنوات الجانبية الفيزيائية Side-Channel] -> تقليل المخاطر برمجياً (Constant-time, ASLR)
```

---

### 2. مصفوفة التهديدات واستراتيجيات الحماية

#### A. هجمات البرمجيات الخبيثة والذاكرة
1. **Buffer Overflows & Stack Smashing:**
   - الحماية: تضمين حارس المكدس `__stack_chk_guard`، وإذا تم التلاعب بالقيمة يستدعي المعالج فوراً `__stack_chk_fail` ويوقف المعالجة دون السماح بتجاوز المكدس.
2. **Double-Free & Use-After-Free:**
   - الحماية: تخصيص محددات ذاكرة (Magic Signatures: `HEAP_MAGIC_ALLOCATED` و `HEAP_MAGIC_FREE`) وكلمة Canary حارسة `0xDEADC0DEBEEFCAFE`، مع إعادة ملء الذاكرة المحررة ببيانات عشوائية (Poisoning 0x55) لمنع إعادة الاستخدام غير القانوني.
3. **Arbitrary Code Execution (W^X):**
   - الحماية: VMM يفرض تلقائياً تعيين بت `PAGE_NX` (No-Execute) لأي صفحة ذاكرة قابلة للكتابة `PAGE_WRITABLE`. لا يمكن لصفحة أن تجمع الصلاحيتين إطلاقاً.

#### B. هجمات الامتيازات والصلاحيات (Privilege Escalation)
1. **الاستيلاء على صلاحيات المارقة:**
   - لا توجد هوية مستخدم مطلقة في النواة (No omnipotent root UID).
   - يتم التحكم في كل مورد عبر تذكرة قدرة (Capability Token).
   - مبدأ التخفيف (Rights Attenuation): لا يمكن لأي عملية تفويض صلاحيات تتجاوز ما تملكه فعلياً.

#### C. الهجمات الفيزيائية وعتاد الأجهزة
1. **هجمات DMA عبر منافذ Thunderbolt / PCIe:**
   - الحماية: عزل مساحات العنونة العتادية بواسطة تقنية IOMMU. منع الأجهزة من قراءة ذاكرة النواة مباشرة دون مراجعة جداول ترجمة العناوين.
2. **التلاعب بنظام الإقلاع (Bootloader / Firmware Tampering):**
   - الحماية: سلسلة ثقة مشفرة (Measured Boot Chain) تتطلب توقيع النواة والتحقق من الـ Hash عبر شريحة TPM 2.0 قبل تسليم التحكم.
3. **سرقة الجهاز واستخراج القرص:**
   - الحماية: تشفير كامل على مستوى كتل التخزين (Block Storage Encryption) مع ربط مفاتيح فك التشفير بحالة مسجلات PCR في TPM.
